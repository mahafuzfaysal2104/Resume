# 🚀 Projects

### Cyber Resilience for an Agribusiness Back Office (AG-3) — Capstone Group Project
*COIT20265: Network & Information Security Capstone Project* · **October 2026**
- Designed and built a complete cybersecurity infrastructure for Plains Pastoral, a small regional Australian agribusiness whose back office (finance, sales and user data) had no network security, monitoring or backup — a common gap that leaves small businesses exposed to ransomware.
- **Network segmentation:** pfSense firewall with VLANs 10, 20, 30 and 40, so a breach in one zone cannot spread to others.
- **APP01 — Secure file server:** Nextcloud with role-based access controls and multi-factor authentication (MFA).
- **MON01 — Security monitoring:** Wazuh SIEM for real-time threat detection and alerting.
- **BKP01 — Isolated encrypted backup:** MinIO and Restic, enabling full recovery after an attack.
- Delivered a working **detect → contain → recover** chain, proven with a live ransomware simulation.
- 🏆 Awarded **Best Project Output — First Place** across all CQUniversity IT capstone groups (T2, 2026).
