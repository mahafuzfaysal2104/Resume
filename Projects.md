### Cyber Resilience for an Agribusiness Back Office — Capstone Project

| | |
|---|---|
| **Course** | COIT20265: Network & Information Security Capstone Project |
| **Date** | October 2026 |
| **Overview** | Designed and built a complete cybersecurity infrastructure for Plains Pastoral, a small regional Australian agribusiness whose back office (finance, sales and user data) had no network security, monitoring or backup. |
| **Network segmentation** | pfSense firewall with VLANs 10, 20, 30 and 40, so a breach in one zone cannot spread to others. |
| **APP01** | Nextcloud file server with access controls and multi-factor authentication (MFA). |
| **MON01** | Wazuh security monitoring to detect threats in real time. |
| **BKP01** | Isolated, encrypted backup server with MinIO and Restic, so the business can recover after an attack. |
| **Outcome** | Delivered a working **detect, contain and recover** chain, proven with a live ransomware simulation. |
| **Award** | 🏆 Best Project Output (First Place) across all CQUniversity IT capstone groups, T2 2026 · [📄 Certificate](Certificates/CQU_Best-Project-Output_First-Place.pdf) |
